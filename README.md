Bythephone es un prototipo de tienda de celulares con páginas informativas para explorar el catálogo, 
consultar cotizaciones y opciones de financiación, conocer garantías y servicios técnicos, revisar preguntas frecuentes 
y simular envíos y seguimiento. La aplicación Java funciona como una demostración independiente en la terminal; 
no está conectada a la página web ni procesa pagos o autenticaciones reales.
