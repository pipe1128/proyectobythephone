BYTHEPHONE — SIMULACIÓN JAVA EN TERMINAL

Requiere Java 8 o posterior. Desde la carpeta del proyecto, compila y ejecuta:

    javac -encoding UTF-8 BythephoneApp.java
    java BythephoneApp

Usa el menú para simular en la terminal las secciones de inicio y catálogo, cotizaciones,
crédito, preguntas frecuentes, garantías, seguimiento de servicio y checkout/envíos.
El programa Java no inicia un servidor y no se conecta con las páginas web.

La aplicación web funciona por separado. Sus datos de demostración se guardan en el
navegador; la simulación Java conserva sus datos solo durante la ejecución. Ninguna de
las dos experiencias procesa pagos, confirma envíos o aprueba créditos reales.
